# E-Commerce Sales Performance Dashboard

## Project Overview
This repository contains an end-to-end Power BI sales analytics dashboard designed to monitor revenue streams, order volumes, profitability, and customer purchasing patterns across multiple regions, categories, and payment channels. By transforming raw order transaction records into interactive visual reports, the dashboard enables stakeholders to track performance metrics and uncover operational inefficiencies.

---

## Key Metrics & Highlights
* **Order Footprint:** Processed and structured dataset covering **5,615+ orders**.
* **Financial Performance:** Tracked **$438K total sales**, **$37K profit**, and **$121K average order value (AOV)** using custom DAX measures.
* **Category Drivers:** Identified **Clothing** as the dominant volume segment (**63% of total orders**) and **Printers** as a major profit contributor generating **$9K in net profit**.
* **Payment Preference:** Discovered Cash on Delivery (**COD**) accounts for **44% of total orders**.

---

## Key Features & Business Insights
* **Dynamic DAX Modeling:** Leveraged custom DAX measures and time-intelligence calculations to calculate running totals, period-over-period growth, and key financial KPIs.
* **Trend & Seasonality Analysis:** Built dynamic time-intelligence slicers to isolate seasonal loss trends and pinpoint profitability drivers across months and geographical locations.
* **Granular Segmentation:** Mapped sales performance down to category, state, and payment method levels[cite: 1, 2].
* **Executive Visualization:** Utilized waterfall charts, KPI cards, and interactive cross-filtering to provide non-technical business leaders with an intuitive breakdown of margin performance and revenue drivers[cite: 1, 2].

## Tech Stack
* **Business Intelligence:** Microsoft Power BI (Desktop & Service)
* **Data Transformation & Modeling:** DAX (Data Analysis Expressions), Power Query
* **Data Sources:** Microsoft Excel / CSV datasets
